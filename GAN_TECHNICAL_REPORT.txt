Basic generator

File: models/generator.py

1. Linear(100, 256)
2. ReLU(inplace=True)
3. Linear(256, 512)
4. ReLU(inplace=True)
5. Linear(512, 1024)
6. ReLU(inplace=True)
7. Linear(1024, 784)
8. Tanh()
9. Reshape to (batch, 1, 28, 28)

The Basic generator has no convolutional layers and no normalization layers.

Basic discriminator
-------------------

File: models/discriminator.py

1. Flatten: 1 x 28 x 28 to 784
2. Linear(784, 512)
3. LeakyReLU(0.2, inplace=True)
4. Linear(512, 256)
5. LeakyReLU(0.2, inplace=True)
6. Linear(256, 1)

The output is one raw logit. There is no sigmoid layer. The raw logit is
passed to BCEWithLogitsLoss.

4. INFERENCE CODE
=================

Fashion inference
-----------------

File: inference/generate_fashion.py

1. Validate count, seed, architecture, and checkpoint path.
2. Construct BasicGenerator or DCGANGenerator.
3. Load checkpoint["generator"] with torch.load.
4. Map tensors to CPU or CUDA.
5. If seed is provided, create torch.Generator(device=active_device),
   call manual_seed(seed), and pass it to torch.randn.
6. Otherwise sample with sample_noise, which calls torch.randn.
7. Call generator.eval().
8. Run generation inside torch.no_grad().
9. Return CPU tensors in normalized [-1, 1] range.

Seeded latent sampling:

generator_seed = torch.Generator(device=active_device)
generator_seed.manual_seed(seed)
noise = torch.randn(
    count, latent_dim, device=active_device, generator=generator_seed
)

Fashion denormalization when saving:

display_images = ((images.detach().cpu() + 1.0) / 2.0).clamp(0.0, 1.0)

Images are converted to uint8 by multiplying by 255, rounded, and saved as
grayscale PNG mode "L". The native image size remains 28 x 28.

There is no resizing or upscaling method in the inference code. Streamlit
display width=180 changes only the display size.

Face inference
--------------

File: inference/generate_faces.py

1. Load FaceGenerator.
2. Load checkpoint["generator"].
3. Call generator.eval().
4. Sample torch.randn(count, latent_dim, ...).
5. Use torch.no_grad().
6. Return CPU tensors.
7. Denormalize from [-1, 1] to [0, 1].
8. Save native 64 x 64 RGB PNG files.

If the face checkpoint is missing, FaceModelUnavailableError is raised. There
is no untrained fallback.

6. PROBLEMS NOTICED
===================

Ranked by likely impact on visual quality.

1. Face GAN is severely undertrained.
   The saved face checkpoint has only epoch=1 and generator loss
   6.315079600681972. One epoch is unlikely to produce high-quality 64 x 64
   faces.

2. Fashion output is inherently limited to 28 x 28 grayscale.
   The model cannot produce photorealistic full-body fashion because the
   training data contains only 28 x 28 one-channel images.

3. The Basic GAN uses fully connected layers instead of spatial convolutions.
   The generator directly maps 100 values to 784 pixels and has no spatial
   inductive bias. This can produce blurry or structurally weak images.

4. The Basic GAN has no normalization layers.
   Neither BasicGenerator nor BasicDiscriminator uses BatchNorm, LayerNorm, or
   InstanceNorm.

5. DCGAN and face generators use multiple ConvTranspose2d layers.
   Transposed convolutions can create checkerboard or grid artifacts depending
   on learned filters and overlap.

6. There is no learning-rate scheduler.
   Both networks use fixed learning rates of 0.0002 for the full run.

7. There is no augmentation or adversarial regularization.
   Label smoothing, spectral normalization, gradient penalty, input noise, EMA,
   and gradient clipping are all NOT FOUND.

8. The Fashion models were trained for only 10 epochs.
   This is a demonstration-length run and does not establish convergence.

9. Basic GAN losses change substantially.
   Basic discriminator loss rises from 0.6643329695470805 to
   1.154562929291715 while generator loss falls to 1.3491695689748344.
   Losses alone do not prove collapse, but the balance should be checked with
   generated samples and diversity.

10. Training sample grids are generated without switching the generator to eval
    mode.
    In training/trainer.py, torch.no_grad() is used, but self.generator.eval()
    is not called before creating epoch samples. DCGAN BatchNorm therefore
    remains in training mode for those previews. App inference correctly calls
    eval().

11. No quantitative image-quality evaluation exists.
    There is no FID, Inception Score, validation metric, or artifact detector.

12. Face preprocessing may distort faces.
    transforms.Resize((64, 64)) directly stretches source images to a square.
    No face alignment or aspect-ratio-preserving crop is implemented.

13. The face dataset identity and count are not enforced by code.
    The README says FFHQ, but the loader accepts any supported images recursively.
    Actual dataset name and image count are NOT FOUND in the loader.


7. KEY CODE SNIPPETS
====================

Basic generator
---------------

class BasicGenerator(nn.Module):
    """Map latent noise vectors to normalized 28x28 grayscale images."""

    def __init__(self, latent_dim: int = 100) -> None:
        super().__init__()
        if latent_dim < 1:
            raise ValueError("latent_dim must be greater than zero")
        self.latent_dim = latent_dim
        self.network = nn.Sequential(
            nn.Linear(latent_dim, 256),
            nn.ReLU(inplace=True),
            nn.Linear(256, 512),
            nn.ReLU(inplace=True),
            nn.Linear(512, 1024),
            nn.ReLU(inplace=True),
            nn.Linear(1024, 784),
            nn.Tanh(),
        )

    def forward(self, noise: Tensor) -> Tensor:
        """Generate images from noise shaped ``(batch, latent_dim)``."""
        if noise.ndim != 2 or noise.shape[1] != self.latent_dim:
            raise ValueError(
                f"noise must have shape (batch, {self.latent_dim}), "
                f"received {tuple(noise.shape)}"
            )
        return self.network(noise).view(-1, 1, 28, 28)


Basic discriminator
-------------------

class BasicDiscriminator(nn.Module):
    """Classify flattened 28x28 grayscale images using output logits."""

    def __init__(self) -> None:
        super().__init__()
        self.network = nn.Sequential(
            nn.Flatten(),
            nn.Linear(784, 512),
            nn.LeakyReLU(0.2, inplace=True),
            nn.Linear(512, 256),
            nn.LeakyReLU(0.2, inplace=True),
            nn.Linear(256, 1),
        )

    def forward(self, images: Tensor) -> Tensor:
        """Return one unnormalized real/fake logit per image."""
        if images.ndim != 4 or tuple(images.shape[1:]) != (1, 28, 28):
            raise ValueError(
                "images must have shape (batch, 1, 28, 28), "
                f"received {tuple(images.shape)}"
            )
        return self.network(images)


Fashion training loop
---------------------

for real_images, _ in loader:
    real_images = real_images.to(self.device)
    batch_size = real_images.shape[0]
    real_targets = torch.ones(batch_size, 1, device=self.device)
    fake_targets = torch.zeros(batch_size, 1, device=self.device)

    self.discriminator_optimizer.zero_grad(set_to_none=True)
    fake_images = self.generator(
        sample_noise(batch_size, self.latent_dim, device=self.device)
    )
    real_loss = self.criterion(
        self.discriminator(real_images), real_targets
    )
    fake_loss = self.criterion(
        self.discriminator(fake_images.detach()), fake_targets
    )
    discriminator_loss = real_loss + fake_loss
    discriminator_loss.backward()
    self.discriminator_optimizer.step()

    self.generator_optimizer.zero_grad(set_to_none=True)
    generated_images = self.generator(
        sample_noise(batch_size, self.latent_dim, device=self.device)
    )
    generator_loss = self.criterion(
        self.discriminator(generated_images), real_targets
    )
    generator_loss.backward()
    self.generator_optimizer.step()


Face training loop
------------------

The complete authoritative implementation is in training/face_trainer.py.
Its core loop is:

for real_images, _ in loader:
    real_images = real_images.to(self.device)
    batch_size = real_images.shape[0]
    real_targets = torch.ones(batch_size, 1, device=self.device)
    fake_targets = torch.zeros(batch_size, 1, device=self.device)

    self.discriminator_optimizer.zero_grad(set_to_none=True)
    fake_images = self.generator(
        torch.randn(batch_size, self.latent_dim, device=self.device)
    )
    discriminator_loss = self.criterion(
        self.discriminator(real_images), real_targets
    ) + self.criterion(
        self.discriminator(fake_images.detach()), fake_targets
    )
    discriminator_loss.backward()
    self.discriminator_optimizer.step()

    self.generator_optimizer.zero_grad(set_to_none=True)
    generated_images = self.generator(
        torch.randn(batch_size, self.latent_dim, device=self.device)
    )
    generator_loss = self.criterion(
        self.discriminator(generated_images), real_targets
    )
    generator_loss.backward()
    self.generator_optimizer.step()
